## 🧠 AI/ML 前沿论文

**[ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://huggingface.co/papers/2607.29677)**
🔬 突破：首个同时评估 value accuracy、record completeness、grounding 和 cost 四个维度的 schema-guided 抽取 benchmark，覆盖 4,869 页、370 份企业文档、8 个业务域、67 种文档类型。此前 benchmark 只测单维准确率，无法反映真实企业场景中"字段缺失"和"证据引用错误"的成本。
⚙️ 工程影响：为 RAG/agent 抽取系统提供了可量化的评估标准——如果团队在做的文档抽取 agent 没有 grounding 评分，这个 benchmark 直接给出缺失的度量维度。

**[Meshy T2: Fast Native Mesh Generation with Flow Matching](https://huggingface.co/papers/2607.28675)**
🔬 突破：用 vertex-set mesh VAE 将网格编码为连续 latent token，配合 flow matching 替代自回归解码，推理速度提升一个数量级（论文报告从秒级降至亚秒级），且消除了自回归的误差累积问题。
⚙️ 工程影响：3D 资产生成从"离线批处理"变为"交互式创作"成为可能——游戏和影视管线中，艺术家可以实时迭代 mesh 生成，而非等待数分钟。

**[From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement](https://huggingface.co/papers/2607.23802)**
🔬 突破：将 RLVR（可验证奖励强化学习）从数学/代码扩展到开放域任务，核心方法是任务变换（task transformation）——把开放任务改造成可自我验证的格式，消除对 reward model 和 LLM judge 的依赖，同时规避 judge 偏差和额外推理成本。
⚙️ 工程影响：开放域 RL 训练的成本结构将改变——不再需要训练/部署独立的 reward model，self-verification 直接复用策略网络，推理开销降低约 30-50%。

**[Scaling Properties of Text Conditioning in Visual Generation](https://huggingface.co/papers/2607.29679)**
🔬 突破：发现 diffusion loss 与 prompt 中"结构化语言"的量呈近似线性关系——用 GPG（白盒似然）和 ED（黑盒属性）两个指标量化结构化程度。此前认为 diffusion loss 不随 token 数缩放，这个发现推翻了该假设。
⚙️ 工程影响：文生图模型的 scaling law 可以像 LLM 一样预测——训练前就能预估增加 prompt 复杂度后的 loss 改善，指导数据配比和模型容量决策。

## 🧠 AI/ML Frontier Papers

**[ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://huggingface.co/papers/2607.29677)**
🔬 Breakthrough: The first schema-guided extraction benchmark to simultaneously evaluate four dimensions—value accuracy, record completeness, grounding, and cost—covering 4,869 pages, 370 enterprise documents, 8 business domains, and 67 document types. Previous benchmarks only measured single-dimensional accuracy, failing to reflect the costs of "missing fields" and "incorrect evidence citations" in real enterprise scenarios.
⚙️ Engineering Impact: Provides a quantifiable evaluation standard for RAG/agent extraction systems—if your team's document extraction agent lacks a grounding score, this benchmark directly supplies the missing metric dimension.

**[Meshy T2: Fast Native Mesh Generation with Flow Matching](https://huggingface.co/papers/2607.28675)**
🔬 Breakthrough: Uses a vertex-set mesh VAE to encode meshes as continuous latent tokens, paired with flow matching to replace autoregressive decoding, achieving an order-of-magnitude inference speedup (reported from seconds to sub-seconds) while eliminating autoregressive error accumulation.
⚙️ Engineering Impact: 3D asset generation shifts from "offline batch processing" to "interactive creation"—in game and film pipelines, artists can iterate on mesh generation in real-time instead of waiting minutes.

**[From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement](https://huggingface.co/papers/2607.23802)**
🔬 Breakthrough: Extends RLVR (Reinforcement Learning with Verifiable Rewards) from math/code to open-domain tasks. The core method is task transformation—converting open-ended tasks into self-verifiable formats, eliminating the need for reward models and LLM judges while avoiding judge bias and extra inference costs.
⚙️ Engineering Impact: The cost structure of open-domain RL training will change—no longer needing to train/deploy separate reward models, as self-verification reuses the policy network directly, reducing inference overhead by roughly 30-50%.

**[Scaling Properties of Text Conditioning in Visual Generation](https://huggingface.co/papers/2607.29679)**
🔬 Breakthrough: Discovers an approximately linear relationship between diffusion loss and the amount of "structured language" in prompts—quantified using GPG (white-box likelihood) and ED (black-box attributes) metrics. This overturns the previous assumption that diffusion loss doesn't scale with token count.
⚙️ Engineering Impact: Text-to-image scaling laws can now be predicted like LLMs—loss improvements from increased prompt complexity can be estimated before training, guiding data mix ratios and model capacity decisions.

## 🧠 AI/ML 最先端論文

**[ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://huggingface.co/papers/2607.29677)**
🔬 ブレークスルー：value accuracy、record completeness、grounding、cost の4次元を同時に評価する初の schema-guided 抽出ベンチマーク。4,869 ページ、370 件のエンタープライズ文書、8 つのビジネスドメイン、67 種類の文書タイプをカバー。従来のベンチマークは単一次元の精度のみを測定しており、実際のエンタープライズシナリオにおける「フィールド欠落」や「根拠引用エラー」のコストを反映できていなかった。
⚙️ エンジニアリングへの影響：RAG/エージェント抽出システムに定量化可能な評価基準を提供する。もしチームが開発中の文書抽出エージェントに grounding スコアがなければ、このベンチマークが欠落している測定次元を直接示してくれる。

**[Meshy T2: Fast Native Mesh Generation with Flow Matching](https://huggingface.co/papers/2607.28675)**
🔬 ブレークスルー：vertex-set mesh VAE を使用してメッシュを連続的な latent token にエンコードし、フローマッチングで自己回帰デコードを置き換えることで、推論速度が一桁向上（論文では秒単位からサブ秒単位へ）。さらに、自己回帰における誤差蓄積の問題も解消。
⚙️ エンジニアリングへの影響：3D アセット生成が「オフラインバッチ処理」から「インタラクティブな創作」へと変わる可能性がある。ゲームや映像制作パイプラインにおいて、アーティストは数分待つ代わりに、メッシュ生成をリアルタイムで反復できるようになる。

**[From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement](https://huggingface.co/papers/2607.23802)**
🔬 ブレークスルー：RLVR（検証可能な報酬を用いた強化学習）を数学/コードからオープンエンドなタスクへ拡張。中核となる方法はタスク変換（task transformation）であり、オープンなタスクを自己検証可能な形式に変換することで、報酬モデルや LLM ジャッジへの依存を排除し、ジャッジのバイアスや追加の推論コストを回避する。
⚙️ エンジニアリングへの影響：オープンエンド領域の RL トレーニングのコスト構造が変わる。独立した報酬モデルのトレーニング/デプロイが不要になり、自己検証がポリシーネットワークを直接再利用するため、推論オーバーヘッドが約 30〜50% 削減される。

**[Scaling Properties of Text Conditioning in Visual Generation](https://huggingface.co/papers/2607.29679)**
🔬 ブレークスルー：diffusion loss とプロンプト内の「構造化言語」の量がほぼ線形関係にあることを発見。GPG（ホワイトボックス尤度）と ED（ブラックボックス属性）の2つの指標で構造化の程度を定量化。従来は diffusion loss はトークン数に応じてスケールしないと考えられていたが、この発見はその仮定を覆すもの。
⚙️ エンジニアリングへの影響：文生成画像モデルのスケーリング則を LLM と同様に予測できるようになる。トレーニング前にプロンプトの複雑さを増やした場合の loss 改善を見積もることができ、データ配分やモデル容量の決定を導く。
