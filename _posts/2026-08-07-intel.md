## 🧠 AI/ML 前沿论文

**[CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal Tasks](https://huggingface.co/papers/2608.06352)**
🔬 突破：推翻"任务只需可执行即可用于训练"的假设——用多求解器对抗校准（multi-solver calibration）识别"求解器间分歧大"的任务并自动修订，使合成任务难度分布与目标求解器能力对齐。实验显示校准后任务集上训练出的 agent 成功率比未校准高 18.7%。
⚙️ 工程影响：终端 agent 训练数据合成从"可执行性验证"升级为"难度自适应校准"，意味着合成数据 pipeline 需要引入求解器池（至少 3 个异构 solver）作为质量门禁，而非仅做语法/执行校验。

**[AgentOPSD: Recursive Self-Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2608.05987)**
🔬 突破：解决长程 agentic 任务中"轨迹级奖励无法归因到关键决策"的问题——用递归的 token 级 teacher-student 对数概率差作为 turn-level 稠密信号，无需 critic 网络。在 3 个长程 agent 基准上比 PPO 基线提升 22.4%，比单层自蒸馏提升 9.1%。
⚙️ 工程影响：RL 训练框架可去掉 critic 分支（省 30-40% 显存），且稠密信号让训练收敛步数减少约 35%。对部署的影响是：agent 策略在长任务（>20 轮）中的决策质量提升，减少无效工具调用。

**[WorldClaw: Agentic 3D Open-World Generation at Scale](https://huggingface.co/papers/2608.05248)**
🔬 突破：将 3D 开放世界生成从"单模型端到端"改为"规划 agent + 分层生成"——规划 agent 将文本 prompt 分解为区域/地形/资产/材质的结构化规格，再逐层生成。在 1km² 级场景上全局空间一致性（重叠区域误差 <0.5m）比现有 SOTA 提升 3.2 倍。
⚙️ 工程影响：3D 资产生成从"一次性生成"变为"可编辑、可复用的资产库"——下游游戏/仿真团队可直接替换单个资产而无需重新生成整个场景，管线从小时级降到分钟级。

**[GST-Bench: Can VLMs Develop Global Spatial Awareness from Video?](https://huggingface.co/papers/2608.05747)**
🔬 突破：首次提出"全局空间-时间感知"基准——要求模型从 6,790 分钟合成视频中推断输入视频中从未出现过的新视角空间关系。现有最强 VLM（GPT-4o 级）在新视角空间推理上准确率仅 41.3%，接近随机（25%），暴露了"局部感知强、全局建模弱"的系统性缺陷。
⚙️ 工程影响：对具身 agent 和自动驾驶的视觉模块是直接警示——当前 VLM 的空间推理能力不足以支撑"从未见过视角"的导航决策，需要显式的空间记忆模块而非纯注意力。

## 🧠 AI/ML Frontier Papers

**[CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal Tasks](https://huggingface.co/papers/2608.06352)**
🔬 Breakthrough: Overturns the assumption that "tasks only need to be executable to be used for training"—uses multi-solver adversarial calibration to identify tasks with "high inter-solver divergence" and automatically revise them, aligning the synthetic task difficulty distribution with the target solver's capabilities. Experiments show agents trained on calibrated task sets achieve 18.7% higher success rates than uncalibrated ones.
⚙️ Engineering impact: Terminal agent training data synthesis upgrades from "executability validation" to "difficulty-adaptive calibration," meaning synthetic data pipelines need to introduce a solver pool (at least 3 heterogeneous solvers) as a quality gate, rather than just syntax/execution validation.

**[AgentOPSD: Recursive Self-Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2608.05987)**
🔬 Breakthrough: Solves the problem of "trajectory-level rewards cannot be attributed to key decisions" in long-horizon agentic tasks—uses recursive token-level teacher-student log-probability differences as turn-level dense signals, without requiring a critic network. Achieves 22.4% improvement over PPO baselines and 9.1% over single-layer self-distillation across 3 long-horizon agent benchmarks.
⚙️ Engineering impact: RL training frameworks can remove the critic branch (saving 30-40% VRAM), and dense signals reduce training convergence steps by approximately 35%. Deployment impact: agent policy decision quality improves in long tasks (>20 turns), reducing ineffective tool calls.

**[WorldClaw: Agentic 3D Open-World Generation at Scale](https://huggingface.co/papers/2608.05248)**
🔬 Breakthrough: Shifts 3D open-world generation from "single-model end-to-end" to "planning agent + hierarchical generation"—the planning agent decomposes text prompts into structured specifications for regions/terrain/assets/materials, then generates layer by layer. Global spatial consistency (overlap region error <0.5m) on 1km²-scale scenes improves 3.2x over existing SOTA.
⚙️ Engineering impact: 3D asset generation shifts from "one-shot generation" to "editable, reusable asset libraries"—downstream game/simulation teams can directly replace individual assets without regenerating entire scenes, reducing pipeline time from hours to minutes.

**[GST-Bench: Can VLMs Develop Global Spatial Awareness from Video?](https://huggingface.co/papers/2608.05747)**
🔬 Breakthrough: First to propose a "global spatio-temporal awareness" benchmark—requires models to infer spatial relationships from novel viewpoints never seen in the input video, using 6,790 minutes of synthetic video. The strongest existing VLM (GPT-4o-class) achieves only 41.3% accuracy on novel-view spatial reasoning, close to random (25%), exposing a systematic deficiency of "strong local perception, weak global modeling."
⚙️ Engineering impact: A direct warning for embodied agents and autonomous driving vision modules—current VLM spatial reasoning capabilities are insufficient for navigation decisions from "never-seen viewpoints," requiring explicit spatial memory modules rather than pure attention.
