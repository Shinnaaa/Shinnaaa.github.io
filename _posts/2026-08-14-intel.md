## 🧠 AI/ML 前沿论文

**[ReRound: Reconstructive Rounding to Resolve Midpoint Ambiguity in Calibration-Free LLM Quantization](https://huggingface.co/papers/2608.11045)**
🔬 突破：标准 RTN 量化在权重接近量化区间中点时，四舍五入方向是任意的，ReRound 用条件扩散模型生成低比特权重的连续重建信号，来引导中点权重的舍入方向。相比 GPTQ 的逐层误差最小化，ReRound 在 4-bit 量化下将困惑度损失从 0.8 降到 0.3（LLaMA-7B 实测）。
⚙️ 工程影响：扩散模型推理开销大，但 ReRound 只在量化阶段运行一次，推理时零额外成本。这意味着 4-bit 量化模型的质量上限被抬高，边缘端部署 7B 模型的可行性提升。

**[From Atomic Evidence to Logical Composition: Structured Compositional Reasoning over Compound Answer Options](https://huggingface.co/papers/2608.12836)**
🔬 突破：LLM 在 AND/OR/NEITHER 复合选项上频繁出错，即使对每个原子判断正确。该框架将复合选项分解为原子答案，用对比假设打分，再用整数线性规划组合分数。在 LOGICAL-COMMONSENSEQA 上准确率提升约 12%。
⚙️ 工程影响：对 RAG 系统的多条件过滤查询（如"找到既懂 Python 又懂 Rust 的工程师"）有直接借鉴价值，但 ILP 求解在实时场景有延迟风险，需评估缓存策略。

**[Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control](https://huggingface.co/papers/2608.12123)**
🔬 突破：形式化了 LLM-agent 控制路径中"就绪队列"的概念——模型调用和工具调用之间的小型确定性转换（路由、状态更新）有多少可以留在 GPU 上执行，避免 CPU 往返。在固定分区共享 F 和精确离线份额 P* 的框架下，证明了在零服务时间、无限容量条件下 P* 可精确计算。
⚙️ 工程影响：对 agent 推理框架（如 LangGraph、CrewAI）的部署架构有直接影响——如果路由决策可以留在 GPU 上，agent 的每轮延迟可减少 5-10ms（CPU 往返开销）。这是 agent 推理从"CPU 编排"走向"GPU 原生"的理论基础。

## 🧠 AI/ML Frontier Papers

**[ReRound: Reconstructive Rounding to Resolve Midpoint Ambiguity in Calibration-Free LLM Quantization](https://huggingface.co/papers/2608.11045)**
🔬 Breakthrough: In standard RTN quantization, when weights are near the midpoint of quantization intervals, the rounding direction is arbitrary. ReRound uses a conditional diffusion model to generate continuous reconstruction signals for low-bit weights, guiding the rounding direction of midpoint weights. Compared to GPTQ's layer-wise error minimization, ReRound reduces perplexity loss from 0.8 to 0.3 at 4-bit quantization (measured on LLaMA-7B).
⚙️ Engineering impact: Diffusion model inference is expensive, but ReRound only runs once during quantization with zero additional cost at inference time. This raises the quality ceiling for 4-bit quantized models, improving the feasibility of edge deployment for 7B models.

**[From Atomic Evidence to Logical Composition: Structured Compositional Reasoning over Compound Answer Options](https://huggingface.co/papers/2608.12836)**
🔬 Breakthrough: LLMs frequently err on AND/OR/NEITHER compound options, even when each atomic judgment is correct. This framework decomposes compound options into atomic answers, scores them with contrastive hypotheses, and combines scores using integer linear programming. Accuracy improves by approximately 12% on LOGICAL-COMMONSENSEQA.
⚙️ Engineering impact: Directly applicable to RAG systems' multi-condition filtering queries (e.g., "find engineers who know both Python and Rust"), but ILP solving poses latency risks in real-time scenarios; caching strategies need evaluation.

**[Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control](https://huggingface.co/papers/2608.12123)**
🔬 Breakthrough: Formalizes the concept of "ready cohorts" in LLM-agent control paths—how many small deterministic transitions between model calls and tool calls (routing, state updates) can remain on the GPU, avoiding CPU round trips. Within a framework of fixed partitioned sharing F and exact offline share P*, proves that P* can be precisely computed under zero service time and infinite capacity conditions.
⚙️ Engineering impact: Directly affects deployment architecture for agent inference frameworks (e.g., LangGraph, CrewAI)—if routing decisions can stay on the GPU, per-turn agent latency can be reduced by 5-10ms (CPU round-trip overhead). This is the theoretical foundation for agent inference moving from "CPU orchestration" to "GPU-native."

**[ReRound: Reconstructive Rounding to Resolve Midpoint Ambiguity in Calibration-Free LLM Quantization](https://huggingface.co/papers/2608.11045)**
🔬 ブレークスルー：標準的なRTN量子化では、ウェイトが量子化区間の中点に近い場合、四捨五入の方向は任意です。ReRound は条件付き拡散モデルを使用して低ビットウェイトの連続再構成信号を生成し、中点ウェイトの丸め方向をガイドします。GPTQ のレイヤーごとの誤差最小化と比較して、ReRound は4ビット量子化でパープレキシティ損失を0.8から0.3に削減します（LLaMA-7B実測）。
⚙️ エンジニアリングへの影響：拡散モデルの推論オーバーヘッドは大きいですが、ReRound は量子化段階で一度だけ実行され、推論時は追加コストゼロです。これは4ビット量子化モデルの品質上限が引き上げられ、エッジ端末での7Bモデル展開の実現可能性が高まることを意味します。

🔬 ブレークスルー：LLM は AND/OR/NEITHER の複合オプションで頻繁にエラーを起こします。各アトミックな判断が正しくてもです。このフレームワークは複合オプションをアトミックな回答に分解し、対比仮説スコアリングを使用し、整数線形計画法でスコアを組み合わせます。LOGICAL-COMMONSENSEQA で精度が約12%向上します。

**[Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control](https://huggingface.co/papers/2608.12123)**
🔬 ブレークスルー：LLMエージェント制御パスにおける「レディキュー」の概念を形式化しました。モデル呼び出しとツール呼び出しの間の小さな決定論的変換（ルーティング、状態更新）のうち、どれだけをGPU上に留めてCPU往復を回避できるかです。固定パーティション共有Fと正確なオフラインシェアP*のフレームワークで、ゼロサービス時間・無限容量条件下でP*が正確に計算可能であることを証明しました。
