## 🧠 AI/ML 前沿论文

**[StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling](https://huggingface.co/papers/2608.15089)**
🔬 突破：不改变模型权重，仅通过优化 agent 执行环境（durable states、phase-local context、checked transitions），将 Terminal-Bench 2.1 准确率从约 70% 拉到 95.3%——证明 long-horizon agent 的失败主因是"执行系统"而非"模型能力"。
⚙️ 工程影响：为 agent 应用提供了一条低成本路径：与其等下一代模型，不如投资构建可恢复的运行时状态管理。单次评估成本 $15 意味着团队可以高频迭代 harness 设计。

**[Valid Per-Field Selective Risk Control for Document Extraction](https://huggingface.co/papers/2608.14639)**
🔬 突破：在 13,859 个真实字段上证明"选择性风险控制"（只接受置信度高的字段）在文档提取中系统性失效——score-refit leakage 导致覆盖率仅 0.416 而风险 0.127，95% 的测试分割违反 α=0.10 的承诺。
⚙️ 工程影响：直接否定了"用模型置信度做字段级质量控制"的常见做法。文档提取系统需要重新设计校准流程，否则"只取高置信度字段"的策略会给出虚假的安全保证。

**[Accuracy and Order Sensitivity Diverge Under Label-Free Strategies](https://huggingface.co/papers/2608.11947)**
🔬 突破：测试两种"无标签"策略（生成-匹配、独立打分）来消除 MCQ 的选项顺序偏差——结果两者都不能可靠提升准确率，且准确率与顺序敏感性在无标签策略下解耦。
⚙️ 工程影响：对依赖 MCQ 做模型评估的团队是警告：选项顺序偏差不是简单的 prompt 工程能修复的，评估结果需要报告顺序敏感性作为独立指标。

## 🧠 AI/ML Frontier Papers

**[StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling](https://huggingface.co/papers/2608.15089)**
🔬 Breakthrough: Without changing model weights, only by optimizing the agent execution environment (durable states, phase-local context, checked transitions), Terminal-Bench 2.1 accuracy was raised from ~70% to 95.3%—proving that the primary cause of long-horizon agent failures is the "execution system" rather than "model capability."
⚙️ Engineering Impact: Provides a low-cost path for agent applications: instead of waiting for the next generation of models, invest in building recoverable runtime state management. A single evaluation cost of $15 means teams can iterate on harness design at high frequency.

**[Valid Per-Field Selective Risk Control for Document Extraction](https://huggingface.co/papers/2608.14639)**
🔬 Breakthrough: Demonstrated across 13,859 real fields that "selective risk control" (only accepting high-confidence fields) systematically fails in document extraction—score-refit leakage results in coverage of only 0.416 with risk at 0.127, and 95% of test splits violate the α=0.10 guarantee.
⚙️ Engineering Impact: Directly refutes the common practice of "using model confidence for field-level quality control." Document extraction systems need to redesign calibration processes; otherwise, the "only take high-confidence fields" strategy provides false safety guarantees.

**[Accuracy and Order Sensitivity Diverge Under Label-Free Strategies](https://huggingface.co/papers/2608.11947)**
🔬 Breakthrough: Tested two "label-free" strategies (generate-match, independent scoring) to eliminate option order bias in MCQs—both fail to reliably improve accuracy, and accuracy decouples from order sensitivity under label-free strategies.
⚙️ Engineering Impact: A warning for teams relying on MCQs for model evaluation: option order bias cannot be fixed by simple prompt engineering, and evaluation results need to report order sensitivity as an independent metric.
