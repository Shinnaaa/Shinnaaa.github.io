## 🧠 AI/ML 前沿论文

**[Bounded Agents: Delegation Security for Multi-Agent AI Systems](https://huggingface.co/papers/2608.15888)**
🔬 突破：指出多 agent 系统的安全漏洞不在"权限过大"而在"权限静态化"——agent 在会话开始时的权限设定后不再变化，且每个请求独立评估，导致 agent 可以把多个单独合法的操作组合成越权结果。提出"有界委托"机制，让子 agent 的权限严格受限于父 agent 的委托范围。
⚙️ 工程影响：对 agent 框架（LangGraph、AutoGen）的权限模型设计有直接影响——需要在会话级别引入动态权限收缩，而非静态 ACL。

**[SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents](https://huggingface.co/papers/2608.18852)**
🔬 突破：识别出"选择器信用饥饿"问题——在长程 agent 任务中，决定"读哪个 skill 文件"的 token 在序列级 advantage 中占的损失份额趋近于零，导致标准 RL 无法训练 skill 选择策略。提出在策略内训练方法，让选择信号直接作用于选择 token。
⚙️ 工程影响：对 agent 框架的 skill 库设计有直接影响——当前"读 skill 文件"的决策是启发式的，该论文提供了可训练的替代方案，但需要 agent 框架暴露选择 token 的梯度。

**[The More Popular, The Harder to Forget: Adaptive Popularity for LLM Unlearning](https://huggingface.co/papers/2608.14229)**
🔬 突破：发现预训练中高频出现的事实比低频事实更难被 unlearning 移除（泄漏量约 5 倍差异），提出 AdaPop 方法，根据事实流行度动态调整遗忘压力，用双上升控制器自动平衡遗忘-保留。
⚙️ 工程影响：对合规性删除（如 GDPR"被遗忘权"）有直接价值——现有 unlearning 方法对热门事实效果差，AdaPop 提供了频率感知的解决方案，但依赖外部流行度代理（如 Wikidata），部署成本需评估。

## 🧠 AI/ML Frontier Papers

**[Bounded Agents: Delegation Security for Multi-Agent AI Systems](https://huggingface.co/papers/2608.15888)**
🔬 Breakthrough: Points out that the security vulnerability in multi-agent systems is not "excessive permissions" but "static permissions"—agent permissions are set at session start and never change, and each request is evaluated independently, allowing agents to combine multiple individually legitimate operations into an unauthorized outcome. Proposes a "bounded delegation" mechanism where sub-agent permissions are strictly limited to the parent agent's delegation scope.
⚙️ Engineering impact: Directly affects permission model design in agent frameworks (LangGraph, AutoGen)—requires dynamic permission contraction at the session level, not static ACLs.

**[SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents](https://huggingface.co/papers/2608.18852)**
🔬 Breakthrough: Identifies the "selector credit starvation" problem—in long-horizon agent tasks, the tokens deciding "which skill file to read" have a loss share approaching zero in sequence-level advantage, making standard RL unable to train skill selection policies. Proposes an in-policy training method where selection signals directly act on selection tokens.
⚙️ Engineering impact: Directly affects skill library design in agent frameworks—current "read skill file" decisions are heuristic; this paper offers a trainable alternative, but requires agent frameworks to expose gradients for selection tokens.

**[The More Popular, The Harder to Forget: Adaptive Popularity for LLM Unlearning](https://huggingface.co/papers/2608.14229)**
🔬 Breakthrough: Finds that facts appearing frequently in pretraining are harder to remove via unlearning than low-frequency facts (~5x leakage difference), proposing the AdaPop method that dynamically adjusts forgetting pressure based on fact popularity, using a dual-ascent controller to automatically balance forgetting-retention.
⚙️ Engineering impact: Direct value for compliance deletion (e.g., GDPR "right to be forgotten")—existing unlearning methods perform poorly on popular facts; AdaPop offers a frequency-aware solution, but relies on external popularity proxies (e.g., Wikidata), requiring deployment cost evaluation.

**[The More Popular, The Harder to Forget: Adaptive Popularity for LLM Unlearning](https://huggingface.co/papers/2608.14229)**
🔬 ブレークスルー：事前学習で高頻度に出現する事実は低頻度の事実よりも unlearning で除去しにくい（漏洩量は約 5 倍の差）ことを発見。事実の人気度に応じて忘却圧力を動的に調整する AdaPop 手法を提案し、二重上昇コントローラで忘却-保持のバランスを自動調整する。
