## 🧠 AI/ML 前沿论文

**[Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement](https://huggingface.co/papers/2609.01481)**  
🔬 突破：将编码 agent 从"单次任务执行"扩展为"多天持续迭代"，通过 repair-capability growth 平衡机制，在 3 天自主开发中使测试通过率从 61% 提升至 78%。核心是让 agent 在修复 bug 的同时学习新能力，而非只做局部修补。  
⚙️ 工程影响：多天自主开发意味着 agent 需要持久化状态管理——包括跨 session 的代码库记忆、失败案例库和迭代策略。现有 harness（如 Claude Code、OpenCode）均无此机制，需要自建状态持久化层。

**[UI-Venus-2 Technical Report](https://huggingface.co/papers/2609.00028)**  
🔬 突破：统一移动/Web/桌面三端 GUI agent 框架，通过环境覆盖扩展和闭环推理-行动架构，在 OSWorld 上任务成功率 34.2%（前代 22.1%），在 AndroidWorld 上 41.7%。关键改进是引入了可验证的 reward 信号，而非仅依赖模型自评。  
⚙️ 工程影响：GUI agent 从 benchmark 到生产的关键是 reward verification——论文提出的"环境反馈作为 reward"方案可直接借鉴到 RPA 工具中，替代当前基于规则匹配的脆弱验证。

**[Qwen-Drive-1.0](https://huggingface.co/papers/2609.00111)**  
🔬 突破：保留预训练 VLM 架构不变，仅通过外挂 BEV 感知头实现 3D 检测、语义占用和地图分割三任务联合，在 nuScenes 上 mAP 47.2%（BEVFormer 为 42.8%）。关键发现是共享表征中已包含足够 3D 信息，无需重新训练主干。  
⚙️ 工程影响：对自动驾驶团队意味着可以复用通用 VLM 权重做感知，而非从零训练专用模型——微调成本从 1000+ GPU 小时降至约 200 GPU 小时。

**[ZimaBlue: Evolving Generalizable World Action Models through Scalable Video Pre-training](https://huggingface.co/papers/2609.00188)**  
🔬 突破：用无动作标签的 egocentric 视频预训练世界动作模型，在 7 个真实机器人操作任务上零样本成功率 62%，对比 RT-2 的 45% 提升 17 个百分点。核心是视频预训练让模型学到物体交互动力学，而非仅视觉特征。  
⚙️ 工程影响：机器人操作训练的数据瓶颈可能被视频预训练打破——团队可先用互联网视频预训练，再用少量真实轨迹微调，将数据采集成本降低一个数量级。

**[E-Commerce Bench](https://huggingface.co/papers/2608.30730)**  
🔬 突破：首个 365 天长周期电商运营 benchmark，要求 agent 同时管理多个店铺、与供应商谈判并应对动态事件。基线测试显示 GPT-4o 在 30 天时利润率为正，但 365 天时因策略僵化转为亏损——长周期任务暴露了 LLM 的探索-利用失衡问题。  
⚙️ 工程影响：长周期 agentic 任务需要显式的经验积累机制（如记忆回放、策略更新），而非仅靠 prompt 工程。对构建自动化运营系统的团队有直接参考价值。

## 🧠 AI/ML Frontier Papers

**[Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement](https://huggingface.co/papers/2609.01481)**  
🔬 Breakthrough: Extends coding agents from "single-task execution" to "multi-day continuous iteration," using a repair-capability growth balancing mechanism to improve test pass rates from 61% to 78% over 3 days of autonomous development. The core idea is to let agents learn new capabilities while fixing bugs, rather than only making local patches.  
⚙️ Engineering impact: Multi-day autonomous development means agents need persistent state management—including cross-session codebase memory, failure case libraries, and iteration strategies. Existing harnesses (e.g., Claude Code, OpenCode) lack this mechanism, requiring a custom state persistence layer.

**[UI-Venus-2 Technical Report](https://huggingface.co/papers/2609.00028)**  
🔬 Breakthrough: Unified GUI agent framework for mobile/Web/desktop, achieving 34.2% task success rate on OSWorld (previous generation: 22.1%) and 41.7% on AndroidWorld through environment coverage expansion and a closed-loop reasoning-action architecture. Key improvement: introducing verifiable reward signals rather than relying solely on model self-evaluation.  
⚙️ Engineering impact: The key to moving GUI agents from benchmark to production is reward verification—the paper's "environment feedback as reward" approach can be directly borrowed into RPA tools, replacing current fragile rule-based matching verification.

**[Qwen-Drive-1.0](https://huggingface.co/papers/2609.00111)**  
🔬 Breakthrough: Preserves the pretrained VLM architecture unchanged, achieving joint 3D detection, semantic occupancy, and map segmentation by attaching a BEV perception head, with mAP 47.2% on nuScenes (BEVFormer: 42.8%). Key finding: shared representations already contain sufficient 3D information, eliminating the need to retrain the backbone.  
⚙️ Engineering impact: For autonomous driving teams, this means reusing general VLM weights for perception instead of training specialized models from scratch—fine-tuning cost drops from 1000+ GPU hours to ~200 GPU hours.

**[ZimaBlue: Evolving Generalizable World Action Models through Scalable Video Pre-training](https://huggingface.co/papers/2609.00188)**  
🔬 Breakthrough: Pre-trains world action models on egocentric videos without action labels, achieving 62% zero-shot success across 7 real robot manipulation tasks, a 17-point improvement over RT-2's 45%. Core insight: video pre-training lets models learn object interaction dynamics, not just visual features.  
⚙️ Engineering impact: The data bottleneck in robot manipulation training may be broken by video pre-training—teams can first pre-train on internet videos, then fine-tune with a small number of real trajectories, reducing data collection costs by an order of magnitude.

**[E-Commerce Bench](https://huggingface.co/papers/2608.30730)**  
🔬 Breakthrough: First 365-day long-horizon e-commerce operations benchmark requiring agents to manage multiple stores simultaneously, negotiate with suppliers, and respond to dynamic events. Baseline tests show GPT-4o achieves positive profit margins at 30 days but turns to losses at 365 days due to rigid strategies—long-horizon tasks expose LLMs' exploration-exploitation imbalance.  
⚙️ Engineering impact: Long-horizon agentic tasks require explicit experience accumulation mechanisms (e.g., memory replay, strategy updates), not just prompt engineering. Directly relevant for teams building automated operations systems.
