## 🧠 AI/ML 前沿论文

**[Post-Training Language Models for Gold-Medal Performance in Coding Competitions](https://huggingface.co/papers/2609.02849)**  
🔬 突破：用 22,000 道精选竞赛题 + 合成推理轨迹 + SFT/RL 管道，将 Nemotron-3-Nano-CC（30B-A3B）训练到 IOI/ICPC 金牌水平——此前同规模模型在 Codeforces 上仅达铜牌水平。核心创新是 GenCorrect 测试时计算策略：迭代生成-反馈-修正，而非单次采样。  
⚙️ 工程影响：30B-A3B 的 MoE 架构意味着单卡 80GB 可部署，金牌级竞赛模型首次进入"本地可跑"区间；GenCorrect 的迭代修正模式可迁移到代码生成以外的推理任务。

**[Cliff: Learning Process Rewards from the First Mistake](https://huggingface.co/papers/2609.02817)**  
🔬 突破：推翻"过程奖励需全程监督"的假设——一旦推理过程首次出错，后续步骤的评估价值趋近于零。Cliff 只对"首个错误"之前的步骤给予奖励，将过程奖励建模从全轨迹压缩到前缀，训练效率提升且无需专用奖励模型。  
⚙️ 工程影响：RLVR 训练中不再需要逐步骤标注或蒸馏教师模型，数据标注成本降低一个量级；对推理链较长的数学/代码任务，可显著减少 RL 训练的不稳定问题。

**[ExecRetrieval: Measuring the Functional-Correctness Gap in Code-Embedding Retrieval](https://huggingface.co/papers/2609.01865)**  
🔬 突破：首次在检索基准中植入"执行等价但词法不同"与"词法相似但执行错误"的对照样本，量化了 embedding 模型的"功能正确性盲区"——现有 embedding 在区分正确代码与近克隆错误代码时，准确率仅比随机略高。  
⚙️ 工程影响：直接冲击 RAG 代码生成管线的假设——"检索到相似代码 = 检索到正确代码"不成立。编码 agent 的检索层需引入执行验证或静态分析作为后置过滤器，而非仅依赖 embedding 相似度。

**[SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models](https://huggingface.co/papers/2609.02886)**  
🔬 突破：解决视频世界模型训练的"数据异构"问题——不同数据集在时间尺度、相机几何、视觉质量上差异巨大，naive 混合导致监督信号不一致。SolarWM 提出可重构的数据管道，统一异构数据源为一致训练格式。  
⚙️ 工程影响：视频生成模型的训练从"单数据集作坊"走向"多源数据工厂"，数据管道成为与模型架构同等重要的工程组件；对长时程（>10 秒）视频生成的可扩展训练有直接参考价值。

## 🧠 AI/ML Frontier Papers

**[Post-Training Language Models for Gold-Medal Performance in Coding Competitions](https://huggingface.co/papers/2609.02849)**  
🔬 Breakthrough: Using 22,000 curated competition problems + synthetic reasoning traces + an SFT/RL pipeline, trained Nemotron-3-Nano-CC (30B-A3B) to gold-medal level at IOI/ICPC—previously, models of similar scale only reached bronze level on Codeforces. The core innovation is the GenCorrect test-time computation strategy: iterative generate-feedback-correct rather than single-shot sampling.  
⚙️ Engineering impact: The 30B-A3B MoE architecture means deployment on a single 80GB GPU is feasible, bringing gold-medal-level competition models into the "locally runnable" range for the first time; GenCorrect's iterative correction mode can transfer to reasoning tasks beyond code generation.

**[Cliff: Learning Process Rewards from the First Mistake](https://huggingface.co/papers/2609.02817)**  
🔬 Breakthrough: Overturns the assumption that "process rewards require full-trajectory supervision"—once the first error occurs in a reasoning process, the evaluation value of subsequent steps approaches zero. Cliff only rewards steps before the "first mistake," compressing process reward modeling from full trajectories to prefixes, improving training efficiency without needing dedicated reward models.  
⚙️ Engineering impact: RLVR training no longer requires step-by-step annotation or distilling teacher models, reducing data annotation costs by an order of magnitude; for math/code tasks with long reasoning chains, it can significantly reduce instability issues in RL training.

**[ExecRetrieval: Measuring the Functional-Correctness Gap in Code-Embedding Retrieval](https://huggingface.co/papers/2609.01865)**  
🔬 Breakthrough: For the first time, embeds "execution-equivalent but lexically different" and "lexically similar but execution-incorrect" contrast samples in retrieval benchmarks, quantifying the "functional correctness blind spot" of embedding models—existing embeddings achieve accuracy only slightly better than random when distinguishing correct code from near-clone incorrect code.
