## 📌 今日要闻

**1. Claude Haiku 5.5 发布：OSWorld 计算机操作从 15.7% 跳到 72.4%，token 价格降幅最高 90%**  
OSWorld 是真实桌面操作基准，15.7→72.4 意味着 Haiku 档位从"能聊天"变成"能替你点鼠标"，这是 agent 产品第一次可以在小模型上跑 GUI 自动化而不烧钱。但新 tokenizer 每任务消耗更多 token，实际账单降幅小于标称的 90%——按 token 单价做预算的团队要重算。 · [HN](https://www.anthropic.com/claude-haiku-5-5) / [The Decoder](https://the-decoder.com/claude-haiku-5-5-arrives-with-massive-price-cuts-proving-the-ai-pricing-arms-race-is-far-from-over/)

**2. OpenAI 发布 GPT-6，ChatGPT 输出从纯文本改为可交互 UI，思考中即可响应，等待时间降 44%**  
"边想边答"把首 token 延迟从"完整推理后"提前到"推理中"，44% 是用户可感知的量级。付费层 GPT-6 Sol / 免费层 GPT-6 Luna 的双档命名说明 OpenAI 把能力分层做进了模型名，而不是靠限速区分。 · [HN](https://openai.com/index/gpt-6-for-everyone/) / [The Decoder](https://the-decoder.com/chatgpt-with-gpt-6-ditches-mostly-text-output-for-interactive-ui-with-charts-buttons-and-mini-apps/) / [TechCrunch](https://techcrunch.com/2026/10/07/chatgpt-is-getting-a-lot-more-visual-with-the-launch-of-a-new-interface/)

**3. Meta 和微软内部限制员工使用 Claude**  
两家同时动手，且发生在 Claude Haiku 5.5 发布当天——不是模型能力问题，是企业采购和数据边界问题。正在推 Claude Code / Claude 企业版的团队，本周要确认自己客户的合规口径是否已经变了。 · [HN](https://www.rswebsols.com/news/meta-and-microsoft-take-steps-to-reduce-employee-usage-of-claude-ai/)

**4. Google SynthID 检测器公开，1800 亿条内容已带水印**  
检测器只认 SynthID 标记，不认其他 AI 生成内容——它是"验证 Google 及合作方（OpenAI、Nvidia）出品"的工具，不是通用 AI 内容检测器。做内容溯源或 UGC 审核的产品，可以把它当"白名单验证"用，不能当"AI 检测"用。 · [The Decoder](https://the-decoder.com/google-says-180-billion-images-and-videos-now-carry-synthid-watermarks-as-detector-goes-public/) / [TechCrunch](https://techcrunch.com/2026/10/07/googles-new-synthid-website-can-identify-ai-generated-media/)

**5. Chrome 开始发布 JPEG XL 支持**  
Chrome 2019 年移除 JPEG XL 支持后，社区靠 flag 续命六年。这次是正式发布，意味着图片 CDN 可以开始按 Accept 头做 JXL 分发——同画质下比 AVIF 编码快、解码省电，但 Safari 和 Firefox 的支持状态决定你能不能真的省掉 WebP 回退。 · [HN](https://developer.chrome.com/blog/jpeg-xl-in-chrome)

**1. Claude Haiku 5.5 released: OSWorld computer operation jumps from 15.7% to 72.4%, token prices cut by up to 90%**

The dual-tier naming of paid-tier GPT-6 Sol / free-tier GPT-6 Luna shows OpenAI has built capability tiering into the model name rather than differentiating via rate limits. · [HN](https://openai.com/index/gpt-6-for-everyone/) / [The Decoder](https://the-decoder.com/chatgpt-with-gpt-6-ditches-mostly-text-output-for-interactive-ui-with-charts-buttons-and-mini-apps/) / [TechCrunch](https://techcrunch.com/2026/10/07/chatgpt-is-getting-a-lot-more-visual-with-the-launch-of-a-new-interface/)

**4. Google SynthID detector goes public, 180 billion pieces of content already watermarked**

Products doing content provenance or UGC moderation can use it as "whitelist verification," not as "AI detection." · [The Decoder](https://the-decoder.com/google-says-180-billion-images-and-videos-now-carry-synthid-watermarks-as-detector-goes-public/) / [TechCrunch](https://techcrunch.com/2026/10/07/googles-new-synthid-website-can-identify-ai-generated-media/)

After Chrome removed JPEG XL support in 2019, the community kept it alive via flags for six years. This is an official release, meaning image CDNs can start doing JXL delivery based on the Accept header—faster encoding and more power-efficient decoding than AVIF at the same quality, but the support status in Safari and Firefox determines whether you can actually drop the WebP fallback. · [HN](https://developer.chrome.com/blog/jpeg-xl-in-chrome)
