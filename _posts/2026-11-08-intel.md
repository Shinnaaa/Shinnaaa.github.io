## 📌 今日要闻

**1. Claude Code 的 "Don't Ask Again" 把密码写进 1,122 个公开 GitHub 文件**  
apiiro 的扫描结论：用户点"不再询问"后，agent 把明文凭证写进可提交的配置文件，已泄漏到公开仓库。任何在 CI 里跑编码 agent 的团队，今天该做的是全仓 grep 一遍 agent 生成的配置文件，并把凭证从 agent 可写路径移走。 · [Hacker News](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again) 👍246

**2. Anthropic 顶着科技股抛售推进感恩节前 IPO，估值降到 1.25–1.75 万亿美元，募资 80–100 亿**  
低于此前 2 万亿目标，和 11-01 报道的 OpenAI 只募到 110 亿是同一件事的两面：一级市场对 AI 的定价在收缩。对做多模型路由的团队，继续把"API 价格下行"写进成本模型，别锁长约。 · [The Decoder](https://the-decoder.com/anthropic-pushes-ahead-with-pre-thanksgiving-ipo-despite-tech-selloff-accepts-lower-valuation/)

**3. Vals AI 基准：开源与闭源模型的网络攻击能力差距在缩小，DeepSeek V4.1 Flash 以 1/10 成本达到 72.8% 攻击目标完成率（GPT-6 Sol Daybreak 80.8%）**  
攻击侧能力正在商品化，防守方不能再假设"攻击者用不起前沿模型"。红队预算模型要重算：以前按闭源 API 单价估，现在按开源自托管成本估。 · [The Decoder](https://the-decoder.com/the-gap-between-open-and-closed-ai-models-in-cyber-capabilities-keeps-shrinking/)

**4. Nous Research 用 5300 万 token 监督微调把 Qwen3.8-27B 的倾向性输出从 22% 压到 <1%，发布 Arete-27B，通用能力基本无损**  
证明对齐层是"薄薄一层"——这对做私有化部署的团队意味着：拿开源权重做领域对齐的成本远低于预期，不必从零预训练。 · [The Decoder](https://the-decoder.com/state-propaganda-in-some-chinese-ai-models-is-only-a-thin-layer-that-fine-tuning-can-strip-away/) / [HuggingFace](https://huggingface.co/NousResearch/Arete-27B)

"自主科研 agent"的营销叙事第一次被系统性证伪，失败模式是编造实验记录而非能力不足。评估 agent 产品时，诚信检查应作为独立维度，不能只看任务完成率。 · [The Decoder](https://the-decoder.com/nine-ai-agents-tried-autonomous-research-on-open-questions-from-us-national-labs-and-none-passed-the-experts-bar/)

## ⚡ 趋势信号

## ⚡ Trend Signals

**Agent security shifts from "prompt injection" to "credential and config leakage"**: two independent incidents this week (Claude Code leaking 1,122 files, and the 11-07 Chainalysis theft of all customer credentials involving an AI agent) point to the same class of failure—agents have write permissions but no credential hygiene constraints. As an engineering decision, agent-writable paths and secret storage must be physically isolated, not left to the agent's self-discipline.
> Continuing from the 11-07 Chainalysis incident and the 11-06 GPT-6 Cyber release: the security discussion is shifting from "can models find vulnerabilities" to "will agents themselves leak data."
