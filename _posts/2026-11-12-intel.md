传统人工形式化验证 Signal 协议核心需数年，Gemini Carbon 驱动的 agent 只把约 1% 的证明标记给人工复核。这是 agent 第一次在"错了就全盘失效"的密码学证明领域产出可交付结果，比 SWE-bench 类分数有意义得多——对做高保证系统的团队，形式化验证从"预算批不下来"变成"先跑一遍 agent 再决定人工投入"。 · [The Decoder](https://the-decoder.com/google-deepminds-alphaproof-code-verified-signals-cryptographic-core-in-four-weeks-instead-of-years/)

## ⚡ 趋势信号

**Agent 的成本结构正在从"模型单价"转向"任务分层"**：shadcn/improve（强模型规划+弱模型执行）、Muse Ember（按内循环 token 设计）、Gemini Decision 1（批量打分降 5 倍成本）三天内三个方向指向同一件事——单模型跑全流程的架构在成本上已经站不住。
> 延续 11-10 的 Fable/Mythos 定价分层与 11-11 Gemini 4 Carbon 成本减半，但今天出现的是工具层而非模型层的应对。

**形式化验证与安全审计成为 agent 的首个"高保证"落地场景**：AlphaProof Code 四周验证 Signal 核心、GPT-6 Cyber 找 81 个 Firefox 漏洞，agent 在可机器验证正确性的任务上先于通用编码任务成熟。选型时把 agent 优先投到"结果可自动验证"的环节，而不是开放式功能开发。
> 与 11-09 Co-Design Bench 的 26.4% 真实任务完成率形成对照：可验证任务上 agent 表现远好于开放式任务。

## ⚡ Trend Signals

**Agent cost structure is shifting from "model unit price" to "task tiering"**: shadcn/improve (strong model plans + weak model executes), Muse Ember (designed around inner-loop tokens), and Gemini Decision 1 (batch scoring at 5x lower cost)—three directions within three days point to the same thing: architectures that run the whole pipeline on a single model no longer hold up on cost.
> Continues 11-10's Fable/Mythos pricing tiering and 11-11's Gemini 4 Carbon halving costs, but today's responses are at the tool layer rather than the model layer.

**Formal verification and security auditing become agents' first "high-assurance" landing scenarios**: AlphaProof Code verifying Signal's core in four weeks, GPT-6 Cyber finding 81 Firefox vulnerabilities—agents mature on tasks with machine-verifiable correctness before general coding tasks. When selecting use cases, prioritize agents for steps where "results can be automatically verified" rather than open-ended feature development.
> Contrasts with 11-09's Co-Design Bench 26.4% real-task completion rate: agents perform far better on verifiable tasks than on open-ended ones.
