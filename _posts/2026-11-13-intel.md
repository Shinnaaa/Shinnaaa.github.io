## ⚡ Trend Signals

**The competitive focus of coding agents is shifting from "capability" to "permission boundaries and compliance auditing"**: three independent events since Wednesday (Goldman revoking Claude Code, Grok Build leaking 35,000 apps, Chainalysis全员 credential theft) point to the same thing—an agent's default permission model matters more than its model score in determining whether it can enter production. Your selection evaluation table should add a column for "list of paths the agent can write to," rather than continuing to compare SWE-bench.
> 11-08 apiiro report that Claude Code wrote credentials into 1,122 public repositories → 11-09 Goldman Sachs revokes Claude Code due to audit boundaries → 11-11 Grok Build leaks 35,000 apps. Within three days it escalated from "configuration error" to "institutional withdrawal"—this is acceleration, not continuation.

**The "single-point breakthrough" strategy for open-weight models is starting to work, but only in coding scenarios**: Ripple-65B (11-07) used $32 million to achieve the top US open-source result on TerminalBench, with mediocre results on other benchmarks; today NVIDIA released two agent skill evaluation frameworks, SkillEvaluator/SkillSpector, in succession, indicating that "skill quality" is becoming a tradable asset independent of model weights. The evaluation focus for private deployment is shifting from "is the model strong enough" to "is the skill library complete enough."
> 11-07 Ripple-65B Apache 2.0 full weights → today NVIDIA SkillEvaluator +108 stars in a single day. Evaluation infrastructure maturing before models is a signal of ecosystem division of labor.
