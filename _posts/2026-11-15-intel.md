## 📌 今日要闻

**1. Lovable 应用泄漏护照信息与 20 万条私信，HN 708👍**  
这是本周第二起"vibe-coding 平台默认配置"事故（前一起是 Grok Build 的 3.5 万应用）。Lovable 生成的应用把 Supabase 表直接暴露给 anon key，任何拿到前端 bundle 的人都能全表读取——问题不在模型，在生成模板把 RLS 关掉了。任何用低代码/AI 生成器上线内部工具、且后端是 Supabase/Firebase 的团队，今天该做的是拿 anon key 跑一遍全表 select。 · [crissyfield.de](https://www.crissyfield.de/research/lovable-en/) / [Hacker News](https://news.ycombinator.com/item?id=45900000)

**2. Nvidia 安全主管 8 月已离职，TechCrunch 追问"安全团队在哪"；11.5 万人联署要求复职黄仁勋**  
安全侧的事实比人事更值得记：黄仁勋辞职的触发链条里，涉事高管所在公司被怀疑向中国转运芯片，而 Nvidia 首席安全官在三个月前就走了。对采购方，这意味着出口合规审查的责任正在向买方转移——本周该确认你的 GPU 供应商合同里，出口管制合规的举证义务写在哪一方。 · [TechCrunch](https://techcrunch.com/2026/11/14/where-was-nvidias-security-team/) / [TechCrunch](https://techcrunch.com/2026/11/14/elon-musk-other-tech-execs-sign-petition-calling-on-nvidia-to-reinstate-jensen-huang/)

**3. Gemini 4 Carbon 拿下 MathArena 第一，但单任务成本是 GPT-6.1 Sol 的 15 倍**  
这是 MathArena 很久以来第一次没有 OpenAI 模型居首，但 15 倍成本差把结论钉死在"数学专项"上：Carbon 在测试中超时限制、几乎不放弃任务，这是用算力换完成率的策略。正在做模型路由的团队，把 Carbon 放进 math/code 分支的兜底位、不要放进默认位，成本模型按 15 倍单独列。 · [The Decoder](https://the-decoder.com/gemini-4-carbon-takes-the-matharena-crown-but-costs-15-times-more-than-gpt-6-1-sol/)

**4. Anthropic 称"think hard"等旧提示词习惯在拖慢 Opus 5.5，建议从 Medium effort 起步**  
Opus 5.5 已成所有付费计划默认模型，官方指南明确要求删掉"think hard"类触发词。这不是提示词玄学：旧习惯会让模型进入长思考路径，在 agent 内循环里直接放大 token 成本。手上跑 Claude 的 agent 流水线，今天该做的是 grep 掉 prompt 模板里的 "think hard / think step by step"，重跑一遍延迟和成本基线。 · [The Decoder](https://the-decoder.com/anthropic-says-outdated-prompting-habits-are-slowing-down-claude-opus-5-5/)

**5. Runway 开源 Praxis-1（Apache 2.0），RoboLab-120 的 World Action Model 分类第一**  
视频预训练权重直接转机器人控制，权重+源码全开。局限官方自己写了：无法规划复杂动作序列。对做具身智能的团队，这是目前唯一能拿到完整训练链路的强基线，值得作为对照跑一遍自家数据。 · [The Decoder](https://the-decoder.com/runways-open-source-praxis-1-turns-video-ai-into-a-robot-controller/)

## ⚡ 趋势信号

**编码 agent 的默认权限边界正在成为独立的安全品类**：三天内两起事故（Grok Build 3.5 万应用、Lovable 20 万私信）都不是模型能力问题，而是生成模板默认关闭鉴权。这会推动 agent 平台把"生成即安全扫描"做进发布流程，采购 agent 平台时"默认 RLS/鉴权配置"该进评估清单。

**前沿模型的能力增长与成本增长开始脱钩**：Gemini 4 Carbon 用 15 倍成本换 MathArena 第一，Anthropic 前研究员称 Mythos 重训只需"原始算力的一小部分"——两边指向同一件事，benchmark 分数与推理成本的对应关系在崩，按旧分数做选型的成本模型全部要重算。

## ⚡ Trend Signals

**The default permission boundary of coding agents is becoming a standalone security category**: two incidents in three days (Grok Build's 35,000 apps, Lovable's 200,000 private messages) were not model-capability problems but generation templates shipping with auth disabled by default. This will push agent platforms to build "generate means security scan" into the release process, and "default RLS/auth configuration" should go on the evaluation checklist when procuring agent platforms.

**Capability growth and cost growth of frontier models are starting to decouple**: Gemini 4 Carbon trades 15x cost for first place on MathArena, while a former Anthropic researcher says retraining Mythos takes only "a fraction of the original compute"—both point to the same thing: the correspondence between benchmark scores and inference cost is collapsing, and every cost model built on old scores for model selection needs to be recalculated.
