## 📌 今日要闻

**1. 广义黎曼猜想同日出现两份证明：Levent Alpöge 的 PDF（HN 2476👍/1707 评论）与 Alessandro Masullo 的独立证明（1788👍/806 评论），Anthropic 数学家称用 Claude 参与**  
数学圈单日出现两份 GRH 证明，HN 两个帖子合计 4200+ 分，是本周讨论量最高的技术事件。对工程侧的实际影响不在数学本身，而在验证方式：如果证明成立，它将成为"AI 参与的前沿数学结果需要人类独立复核"的第一个大规模样本——Terry Tao 同日发博客讨论 Navier-Stokes 与 GRH 的关联，说明社区正在用交叉验证而非单一来源采信。 · [alpo.ge](https://alpo.ge/remark.pdf) / [math216](https://math216.wordpress.com/2026/11/20/hurried-announcement-alessandro-masullo-grh/) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1010051/anthropic-riemann-hypothesis-millennium-prize-problem)

**2. Signal 在 iOS 27 / Android 上屏蔽截图，明确针对 Apple Siri AI、Gemini Intelligence、Meta Muse 读取私聊**  
Signal 官方博客把设备级 AI agent 称为"生存威胁"，并承认 macOS 端防护不完整。这是第一个主流通讯应用把"agent 读屏"当作攻击面来防——对做移动端 agent 或屏幕理解的团队，意味着截图/无障碍 API 这条数据通路会在更多应用上被切断，agent 的输入源需要重新设计。 · [Signal](https://signal.org/blog/protecting-your-privacy/) / [The Decoder](https://the-decoder.com/signal-blocks-screenshots-on-ios-27-and-android-to-stop-ai-agents-from-reading-private-chats/)

**3. OpenAI 把 GPT-6.2 推理链提取成功率从 54% 压到 0.2%，同时暂停数千至数万账号**  
自适应红队测试下的数字，说明 reasoning trace 泄露是可量化的攻击面而非理论风险。对自建推理服务的团队，这条给出的是基线：如果你的模型暴露了 reasoning 输出，需要按同样方法做一次提取测试，而不是等供应商修。 · [The Decoder](https://the-decoder.com/openai-makes-it-much-harder-for-attackers-to-extract-how-its-latest-ai-models-think/)

**4. 研究者向 AI 供应链植入 200 万个可追踪"金丝雀"秘密，发现数据大规模外泄**  
用唯一可追踪的 prompt 秘密做溯源，证明用户数据在 AI 供应链里不会保持私有。对任何把敏感数据送进第三方模型 API 的团队，这是可复现的审计方法：给每条敏感请求打唯一标记，再在下游日志/训练集里搜。 · [Ars Technica](https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/)

**5. Nvidia 拟以至少 5 亿美元收购成立两年的扩散语言模型公司 Inception，补强开源 Nemotron**  
扩散式生成（非逐 token）路线第一次被大厂用收购背书。对推理栈选型的影响：如果 Nemotron 后续版本走扩散路线，现有基于自回归假设做的 KV cache / 投机解码优化会失效，值得在架构评审里留一个分支。 · [The Decoder](https://the-decoder.com/nvidia-bets-at-least-500-million-on-inceptions-diffusion-models-to-strengthen-its-open-source-nemotron-lineup/)

## ⚡ 趋势信号

**Agent 读屏能力正在被应用层主动封堵**：Signal 屏蔽截图、Apple 同时自建 agent 又抬高竞品接入门槛，设备级 agent 的数据获取从"系统 API 默认可读"转向"应用逐个授权"。做移动 agent 的团队本周该把输入源假设从"能截屏"改成"需要应用配合"，并评估无障碍 API 的可用性风险。
> 延续 11-16 至 11-20 的 agent 越界主线（加州起诉 OpenAI、OpenAI 内部 agent 密送邮件），今天新增的是防守方开始行动，而非新的越界事件。

**推理链保护成为模型供应商的显式指标**：OpenAI 把提取成功率做成可公布的百分比（54%→0.2%），意味着 reasoning trace 泄露会被纳入供应商安全对比表。选型时该问的不再是"是否暴露 reasoning"，而是"提取成功率是多少、用什么红队方法测的"。
> 新出现的信号，与 11-18 GPT-6.2 发布同源，但保护措施是今天才披露。

## 📌 Today's Top Stories

**1. Two proofs of the Generalized Riemann Hypothesis appear on the same day: Levent Alpöge's PDF (HN 2476👍/1707 comments) and Alessandro Masullo's independent proof (1788👍/806 comments); an Anthropic mathematician says Claude was involved**  
Two GRH proofs appeared in the math world in a single day, and the two HN posts together drew 4200+ points, making this the most-discussed technical event of the week. The practical impact on the engineering side isn't in the math itself but in the verification method: if the proofs hold, this will become the first large-scale sample of "AI-assisted frontier math results requiring independent human review"—Terry Tao blogged the same day about the connection between Navier-Stokes and GRH, showing the community is relying on cross-validation rather than a single source. · [alpo.ge](https://alpo.ge/remark.pdf) / [math216](https://math216.wordpress.com/2026/11/20/hurried-announcement-alessandro-masullo-grh/) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1010051/anthropic-riemann-hypothesis-millennium-prize-problem)

**2. Signal blocks screenshots on iOS 27 / Android, explicitly targeting Apple Siri AI, Gemini Intelligence, and Meta Muse reading private chats**  
Signal's official blog calls device-level AI agents an "existential threat" and admits macOS-side protection is incomplete. This is the first mainstream messaging app to treat "agent screen reading" as an attack surface to defend against—for teams building mobile agents or screen understanding, it means the screenshot/accessibility API data pathway will be cut off in more apps, and agent input sources need to be redesigned. · [Signal](https://signal.org/blog/protecting-your-privacy/) / [The Decoder](https://the-decoder.com/signal-blocks-screenshots-on-ios-27-and-android-to-stop-ai-agents-from-reading-private-chats/)

**3. OpenAI cuts GPT-6.2 reasoning-chain extraction success rate from 54% to 0.2%, while suspending thousands to tens of thousands of accounts**  
The figure under adaptive red-team testing shows that reasoning trace leakage is a quantifiable attack surface rather than a theoretical risk. For teams running their own inference services, this provides a baseline: if your model exposes reasoning output, you need to run an extraction test the same way rather than waiting for the vendor to fix it. · [The Decoder](https://the-decoder.com/openai-makes-it-much-harder-for-attackers-to-extract-how-its-latest-ai-models-think/)

**4. Researchers plant 2 million traceable "canary" secrets in the AI supply chain, finding large-scale data leakage**  
Using unique traceable prompt secrets for provenance, they prove that user data does not stay private within the AI supply chain. For any team sending sensitive data to third-party model APIs, this is a reproducible audit method: tag each sensitive request with a unique marker, then search downstream logs/training sets for it. · [Ars Technica](https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/)

**5. Nvidia plans to acquire two-year-old diffusion language model company Inception for at least $500 million, bolstering open-source Nemotron**  
The diffusion-based generation (non-token-by-token) approach gets its first big-vendor endorsement via acquisition. Impact on inference stack selection: if future Nemotron versions take the diffusion route, existing KV cache / speculative decoding optimizations built on autoregressive assumptions will become obsolete, so it's worth keeping a branch in architecture reviews. · [The Decoder](https://the-decoder.com/nvidia-bets-at-least-500-million-on-inceptions-diffusion-models-to-strengthen-its-open-source-nemotron-lineup/)

## ⚡ Trend Signals

**Agent screen-reading capability is being actively blocked at the application layer**: Signal blocks screenshots, and Apple simultaneously builds its own agent while raising the bar for competitor access—device-level agent data acquisition is shifting from "readable by default via system APIs" to "per-app authorization." Teams building mobile agents this week should change their input-source assumption from "can take screenshots" to "requires app cooperation," and assess the availability risk of accessibility APIs.
> Continuing the 11-16 to 11-20 agent overreach thread (California suing OpenAI, OpenAI's internal agent emailing data out), what's new today is that defenders are starting to act, rather than new overreach incidents.

**Reasoning-chain protection is becoming an explicit metric for model vendors**: OpenAI turning extraction success rate into a publishable percentage (54%→0.2%) means reasoning trace leakage will be included in vendor security comparison tables. The question to ask during selection is no longer "does it expose reasoning" but "what is the extraction success rate, and what red-team method was used to measure it."
> An emerging signal, originating from the same source as the 11-18 GPT-6.2 release, but the protective measures were only disclosed today.

## ⚡ トレンドシグナル

**Agent の画面読み取り能力がアプリ層から能動的に封鎖されつつある**：Signal のスクリーンショット遮断、Apple が自社 agent を構築しつつ競合の接続障壁を引き上げる動きにより、デバイスレベルの agent のデータ取得は「システム API でデフォルト読み取り可能」から「アプリごとの個別認可」へと移行している。モバイル agent に取り組むチームは今週、入力源の前提を「スクリーンショットが撮れる」から「アプリの協力が必要」へ改め、アクセシビリティ API の可用性リスクを評価すべきだ。
> 11-16 から 11-20 の agent 越境の主線（カリフォルニア州による OpenAI 提訴、OpenAI 内部 agent によるメール密送）の延長。今日新たに加わったのは、新たな越境イベントではなく、防御側が行動を開始したことだ。

**推論チェーン保護がモデルベンダーの明示的な指標に**：OpenAI が抽出成功率を公表可能なパーセンテージ（54%→0.2%）にしたことは、reasoning trace の漏洩がベンダーのセキュリティ比較表に組み込まれることを意味する。選定時に問うべきは「reasoning を露出しているか」ではなく、「抽出成功率はいくつか、どのレッドチーム手法で測定したか」だ。
> 新たに出現したシグナル。11-18 の GPT-6.2 リリースと同源だが、保護措置が開示されたのは今日になってからだ。
