## 📌 今日要闻

**1. Lean/Mathlib 社区正式确认 Alpöge 的黎曼猜想证明正确，17M 行代码经数十名独立验证者复核**  
昨天还是"两份证明互相竞争"，今天变成"一份被机器验证通过"——这是形式化验证第一次成为前沿数学结果的最终裁决者，而不是同行评议的补充。对工程侧的意义：Lean 4 工具链在 1700 万行规模上跑通了完整验证流程，任何评估用 Lean 做协议/合约/密码学证明的团队，现在有了一个真实的规模基准可以测编译时间和 trusted base 大小。 · [The Decoder](https://the-decoder.com/lean-and-mathlib-community-officially-confirms-levent-alpoges-proof-of-the-riemann-hypothesis-is-correct/) / [John Carlos Baez](https://johncarlosbaez.wordpress.com/2026/11/22/masullo-on-the-riemann-hypothesis/)

**2. AI coding agent 在模拟真实职场中完成不到 1/10 的任务，Opus 5.5 与 Astra 均未过线**  
隔离单元测试里接近满分，放进有同事、看板、不完整交接的模拟工位后崩到个位数——这个落差比任何 benchmark 分数都更能说明当前 agent 的能力边界在哪：不是写代码，是维持跨会话的任务状态和处理模糊输入。正在给团队铺 agent 工作流的，该把评估集从"单函数补全"换成"连续关三个 ticket"，否则上线后的实际吞吐会远低于预期。 · [The Decoder](https://the-decoder.com/ai-coding-agents-ace-isolated-tests-but-complete-fewer-than-one-in-ten-tasks-in-a-simulated-workplace/)

**3. Dragos 用 200 万次假请求测出廉价推理供应链漏洞：至少 3 家供应商被攻陷、数百个 AWS key 被窃、转售商直接读客户请求**  
便宜推理 API 的价格差有一部分来自"你的 prompt 就是他们的收入"——转售商在链路中间明文读取请求。OpenRouter 已下架相关供应商。任何把生产流量路由到非一线推理商的团队，本周该做的是审计路由表里每一个中转层，确认 key 是否在供应商侧可解密。 · [The Decoder](https://the-decoder.com/security-researchers-show-how-cheap-ai-inference-providers-steal-keys-and-snoop-on-users/)

**4. Perplexity 发布 Monitor API：按计划搜索、只在检测到变化时通过 webhook 通知 agent**  
把 web 搜索从"一次性查询"变成"持续哨兵"，自带决策模型过滤无关结果。对已经在用 cron + 抓取 + diff 自建监控的团队，这是第一个把"变化检测"做成 API 原语的方案；局限是判断"什么算重要变化"完全交给 Perplexity 的模型，误报/漏报无法本地调参。 · [The Decoder](https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog/)

**5. METR 警告：模型能力提升速度快于安全评测的可靠性，现有数据无法排除危险的加速**  
Opus 5.5 和 GPT-6 Astra 在研究任务上进步快，但测量本身在失效——同时 METR 也说常见测试可能高估模型能力。两头都不准，意味着你手上那套固定评测集做选型的做法正在失去意义，需要改成按任务族滚动重测。 · [The Decoder](https://the-decoder.com/ai-is-getting-better-faster-than-experts-can-reliably-test-whether-new-systems-are-safe-metr-warns/)

## ⚡ 趋势信号

**形式化验证从"数学圈的事"变成"可审计的公共基础设施"**：黎曼猜想证明的最终裁决权落在 Lean 检查器而非期刊，17M 行代码 + 数十名独立验证者构成了第一个大规模可信基础样本。工程侧的直接后果是 Lean 4 的编译时间、内存和 trusted base 审计工具会成为下一个被拿来压测的对象，而不是只在小规模合约验证里出现。
> 延续 11-21/11-22 的 GRH 事件，但性质变了：从"两份证明谁对"转为"机器验证已给出结论"，这是新出现的阶段。

**推理供应链的信任成本开始显性化**：Dragos 的实测把"廉价推理 = 数据裸奔"从猜测变成有数字的实证（3 家被攻陷、数百 AWS key 泄露）。叠加本周 Anthropic 上市后 API 降价空间收窄，模型路由的成本模型里必须新增一项"供应商可信度"权重，纯按价格排序的路由表会踩雷。
> 延续 11-20 "前沿 vs 开源价差拉大"的信号，但方向反转了一半：便宜的代价现在有了具体的安全账单。

## 📌 Today's Top Stories

**1. The Lean/Mathlib community officially confirms Alpöge's proof of the Riemann Hypothesis is correct; 17M lines of code reviewed by dozens of independent verifiers**  
Yesterday it was "two competing proofs"; today it's "one proof machine-verified" — the first time formal verification has served as the final arbiter of a frontier mathematics result rather than a supplement to peer review. What this means for engineering: the Lean 4 toolchain ran a complete verification pipeline at 17 million lines of scale, so any team evaluating Lean for protocol/contract/cryptography proofs now has a real scale benchmark for measuring compile times and trusted base size. · [The Decoder](https://the-decoder.com/lean-and-mathlib-community-officially-confirms-levent-alpoges-proof-of-the-riemann-hypothesis-is-correct/) / [John Carlos Baez](https://johncarlosbaez.wordpress.com/2026/11/22/masullo-on-the-riemann-hypothesis/)

**2. AI coding agents complete fewer than 1/10 of tasks in a simulated workplace; neither Opus 5.5 nor Astra clears the bar**  
Near-perfect scores on isolated unit tests collapse to single digits once placed in a simulated workstation with colleagues, a kanban board, and incomplete handoffs — a gap that says more about where current agents' capabilities end than any benchmark score: it's not writing code, it's maintaining task state across sessions and handling ambiguous input. If you're rolling out agent workflows for your team, switch your eval set from "single-function completion" to "close three tickets in a row," or your real-world throughput after launch will fall far short of expectations. · [The Decoder](https://the-decoder.com/ai-coding-agents-ace-isolated-tests-but-complete-fewer-than-one-in-ten-tasks-in-a-simulated-workplace/)

**3. Dragos uses 2 million fake requests to expose vulnerabilities in the cheap inference supply chain: at least 3 providers compromised, hundreds of AWS keys stolen, resellers reading customer requests directly**  
Part of the price gap in cheap inference APIs comes from "your prompt is their revenue" — resellers read requests in plaintext in the middle of the chain. OpenRouter has delisted the providers involved. If your team routes production traffic to non-frontier inference providers, this week's task is to audit every intermediary layer in your routing table and confirm whether keys are decryptable on the provider side. · [The Decoder](https://the-decoder.com/security-researchers-show-how-cheap-ai-inference-providers-steal-keys-and-snoop-on-users/)

**4. Perplexity launches the Monitor API: scheduled searches that notify agents via webhook only when a change is detected**  
It turns web search from a "one-off query" into a "continuous sentinel," with a built-in decision model filtering out irrelevant results. For teams already building monitoring with cron + scraping + diff, this is the first solution that makes "change detection" an API primitive; the limitation is that deciding "what counts as an important change" is entirely delegated to Perplexity's model, with no local tuning for false positives/negatives. · [The Decoder](https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog/)

**5. METR warns: model capabilities are improving faster than safety evaluations can be made reliable; existing data cannot rule out dangerous acceleration**  
Opus 5.5 and GPT-6 Astra are advancing quickly on research tasks, but the measurements themselves are breaking down — and METR also says common tests may overestimate model capabilities. Both ends are unreliable, which means your fixed eval set for model selection is losing its meaning; you need to switch to rolling re-testing by task family. · [The Decoder](https://the-decoder.com/ai-is-getting-better-faster-than-experts-can-reliably-test-whether-new-systems-are-safe-metr-warns/)

## ⚡ Trend Signals

**Formal verification is shifting from "a mathematics-community matter" to "auditable public infrastructure"**: final authority over the Riemann Hypothesis proof rests with the Lean checker rather than a journal, and 17M lines of code plus dozens of independent verifiers constitute the first large-scale trusted-base sample. The direct engineering consequence is that Lean 4's compile times, memory, and trusted-base auditing tools will become the next things put under stress testing, rather than appearing only in small-scale contract verification.
> Continues the 11-21/11-22 GRH story, but the nature has changed: from "which of the two proofs is right" to "machine verification has reached a conclusion" — a newly emerged phase.

**The trust cost of the inference supply chain is becoming explicit**: Dragos's measurements turn "cheap inference = data running naked" from speculation into evidence with numbers (3 providers compromised, hundreds of AWS keys leaked). Combined with narrowing room for API price cuts after Anthropic's IPO this week, the cost model for model routing must now add a "provider trustworthiness" weight; routing tables sorted purely by price will hit landmines.
> Continues the 11-20 signal of "the price gap between frontier and open source widening," but the direction has half-reversed: cheap now comes with a concrete security bill.

安価な推論 API の価格差の一部は「あなたの prompt が彼らの収入」から来ている——リセラーが経路の途中でリクエストを平文で読んでいる。OpenRouter は関連プロバイダをすでに下架した。本番トラフィックを非大手推論プロバイダにルーティングしているチームが今週やるべきは、ルーティングテーブルの中継層を一つずつ監査し、key がプロバイダ側で復号可能か確認することだ。 · [The Decoder](https://the-decoder.com/security-researchers-show-how-cheap-ai-inference-providers-steal-keys-and-snoop-on-users/)

**4. Perplexity が Monitor API を発表：スケジュールに従って検索し、変化を検出したときだけ webhook でエージェントに通知**  
Web 検索を「単発のクエリ」から「継続的な見張り番」に変え、無関係な結果をフィルタする判定モデルを内蔵。すでに cron + スクレイピング + diff で自前監視を組んでいるチームにとって、これは「変化検出」を API プリミティブにした最初のソリューションだ。限界は「何を重要な変化とみなすか」の判断が完全に Perplexity のモデル任せで、誤検知/見逃しをローカルでチューニングできないこと。 · [The Decoder](https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog/)

**5. METR の警告：モデル能力の向上速度が安全評価の信頼性を上回り、既存データでは危険な加速を排除できない**  
Opus 5.5 と GPT-6 Astra は研究タスクで急速に進歩しているが、測定自体が機能しなくなっている——同時に METR は、一般的なテストがモデル能力を過大評価する可能性があるとも述べている。どちらも不正確ということは、手持ちの固定評価セットで選定するやり方が意味を失いつつあり、タスクファミリーごとにローリングで再測定する方式に変える必要がある。 · [The Decoder](https://the-decoder.com/ai-is-getting-better-faster-than-experts-can-reliably-test-whether-new-systems-are-safe-metr-warns/)

## ⚡ トレンドシグナル

**形式検証が「数学界の話」から「監査可能な公共インフラ」へ**：リーマン予想証明の最終裁定権はジャーナルではなく Lean チェッカーに委ねられ、1700万行のコード + 数十名の独立検証者が最初の大規模な信頼基盤サンプルを構成した。エンジニアリング側の直接的な帰結として、Lean 4 のコンパイル時間・メモリ・trusted base 監査ツールが、小規模なコントラクト検証にのみ現れるのではなく、次に負荷テストされる対象となる。
> 11-21/11-22 の GRH 事件の延長だが、性質が変わった：「2つの証明のどちらが正しいか」から「機械検証が結論を出した」へ。これは新たに出現した段階だ。

**推論サプライチェーンの信頼コストが顕在化し始めた**：Dragos の実測が「安価な推論 = データ丸裸」を推測から数字を伴う実証（3社侵害、数百の AWS key 漏洩）に変えた。今週の Anthropic 上場後の API 値下げ余地の縮小も重なり、モデルルーティングのコストモデルには「プロバイダ信頼度」の重みを新たに加える必要がある。価格だけで並べたルーティングテーブルは地雷を踏む。
> 11-20 の「フロンティア vs オープンソースの価格差拡大」シグナルの延長だが、方向は半分反転した：安さの代償に具体的なセキュリティ請求書が付くようになった。
