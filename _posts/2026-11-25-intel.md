**1. OpenAI 预印本称矩阵乘法指数上界压到 9/4，HN 455👍/221 评论**

**2. Anthropic 股价跌破 $83 发行价，上市 5 天**

两年前发布的协议标准，现在月下载 7 亿次，新增的三项能力都指向"agent 长时间自主运行"——后台任务让工具调用不再阻塞会话，追问用户让 agent 在信息不足时主动停下。对已经在跑 MCP server 的团队：后台任务改变了超时和幂等设计的前提，现有 server 需要重新审视长任务的取消语义。 · [The Decoder](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/)

## 📌 Today's Top Stories

**1. OpenAI preprint claims the matrix multiplication exponent upper bound is pushed down to 9/4, HN 455👍/221 comments**  
Pushing the theoretical upper bound further down beyond Strassen (n^2.807) and the 2024 AlphaTensor-family improvements—the paper is hosted in the openai/math repository rather than on arXiv. OpenAI is turning mathematical proofs into a public proving ground for model capabilities. For the engineering side: the theoretical exponent doesn't change any BLAS implementation today, but the 221 comments center on "whether the proof has been formally verified"—this has become the default follow-up question since the Lean verification of the Riemann hypothesis. · [Hacker News](https://news.ycombinator.com/item?id=50634426) / [paper](https://github.com/openai/math/blob/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/paper.pdf)

The IPO that priced at $83 on 11-20 and raised 105 billion fell below its offer price today. The direct transmission to engineering decisions is API pricing: a public company must answer to quarterly earnings, so room for price cuts narrows, while the open-source side (Fireworks' stance + token prices down 21% in six weeks) keeps pushing lower, and the frontier/open-source price gap will widen. Teams currently building model-routing cost models should recompute this week "which requests must go to frontier models." · [TechCrunch](https://techcrunch.com/2026/11/24/anthropic-shares-fall-below-ipo-price-a-worrying-sign-for-ai-startups/)

**3. MCP SDK monthly downloads top 700 million; protocol expands with background tasks, asking users follow-up questions, and file uploads**  
Two years after its release, the protocol standard now sees 700 million monthly downloads. All three new capabilities point toward "agents running autonomously for long periods"—background tasks keep tool calls from blocking the session, and asking users follow-up questions lets agents proactively stop when information is insufficient. For teams already running MCP servers: background tasks change the premises of timeout and idempotency design, and existing servers need to re-examine the cancellation semantics of long-running tasks. · [The Decoder](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/)

**4. Claude Artifacts can be packaged directly into macOS/Windows desktop apps, even on free accounts**  
Artifacts generated in chat can now be installed as native apps, complete with menu bar items, system notifications, and transparent windows. This appeared the same day as Claude Ship (agents autonomously reviewing and approving PRs)—Anthropic is pushing Claude from a "conversation window" toward a "runtime that can ship"—artifacts becoming distributable binaries means one whole layer of frontend engineering is removed between internal tool prototype and delivery. · [The Decoder](https://the-decoder.com/anthropic-turns-claude-artifacts-into-standalone-desktop-apps-for-macos-and-windows/) / [Product Hunt](https://www.producthunt.com/products/claude-code)

**5. Check Point security management servers hit by active intrusion, HN 276👍/141 comments**  
GreyNoise disclosed an in-the-wild attack campaign targeting Check Point security gateway management planes. The security management server is the central point for network-wide policies and credentials; once compromised, it's equivalent to gaining configuration control over all protected network segments—an order of magnitude larger blast radius than a single edge vulnerability. What to do this week: confirm whether the management plane is exposed to the public internet and whether two-factor authentication is enforced. · [GreyNoise](https://www.greynoise.io/blog/check-point-security-management-servers-intrusion-campaign)
