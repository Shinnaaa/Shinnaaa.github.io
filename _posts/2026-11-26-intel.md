## 📌 今日要闻

**1. 1Password 内部系统被入侵，攻击者拿到员工企业账号与部分客户信息，HN 1322👍/553 评论**  
密码管理器是供应链信任链的最上游——这次是内部系统而非加密库，但"员工账号"这个入口说明企业密码管理器的 SSO 与权限分层需要重新审。正在用 1Password Business 的团队，本周该查的是管理员账号的硬件密钥强制策略和审计日志导出。 · [1Password](https://1password.com/blog/update-on-nov-2026-security-incident) / [TechCrunch](https://techcrunch.com/2026/11/25/1password-said-hackers-broke-into-its-internal-systems-but-customer-passwords-are-safe/)

**2. OpenAI 合并 Chat 与 Work 为单一用量表，Astra 触限快 40%、Sol 快 25%**  
同一订阅额度现在被聊天和 agent 工作流共享，重度 agent 用户的可用额度实质缩水。做 agent 编排的团队要把 token 预算从"按模型"改成"按账号总配额"建模，否则生产任务会在月中被聊天流量挤掉。 · [TechCrunch](https://techcrunch.com/2026/11/25/openai-says-heavy-chatgpt-users-may-hit-limits-sooner-as-it-merges-chat-and-work/) / [HN](https://twitter.com/thsottiaux/status/2125784147889393806)

**3. Google Research 公开 Cogentic 系列论文：整数分解、离散对数，HN 480👍/344 评论**  
分解与离散对数是 RSA/DH 的数学底座，Google 把这类结果集中放出而非单篇 arXiv，评论集中在"是否含量子或新算法路径"。对工程侧：现在不动任何密钥长度，但任何做长期数据留存加密（harvest-now-decrypt-later）评估的团队，这批论文是更新威胁模型时间线的输入。 · [GitHub](https://github.com/google-research/google-research/tree/master/cogentic_research_papers)

**4. S&P 考虑下调 Nvidia 信用评级至 AA-，理由是治理与"关键人风险"**  
上周罢免又复任的治理事件开始传导到信用市场。对采购方：Nvidia 的长期供货承诺与融资租赁条款的对手方风险被评级机构正式定价，正在谈多年 GPU 长约或 GPU 抵押融资的团队，合同里该加治理事件触发的重谈条款。 · [TechCrunch](https://techcrunch.com/2026/11/25/sp-considers-nvidia-credit-downgrade-over-governance-and-key-man-risks/)

**5. OpenAI 测试 Private Inference：企业可在最强模型上查询而 OpenAI 无法读取数据**  
这是对"数据不出境/不入第三方"合规卡点的直接回应，也是 OpenAI 抢企业敏感工作负载的入场券。评估私有化部署（vLLM 自托管）的团队，现在多了一个"托管但不可见"的中间选项，本周该做的是拿自己的合规清单逐条比对 Private Inference 的承诺边界。 · [The Decoder](https://the-decoder.com/openai-wants-companies-to-trust-it-with-sensitive-work-by-promising-not-to-look-at-their-data/)

**フロンティアモデルの枠は「モデル単位」から「アカウント総量」へと縮小しつつある**：OpenAI の Chat/Work 使用量テーブル統合、Anthropic の上場後の値下げ余地の縮小、この二つの線は同じ方向を向いている——クローズドソース側の限界コストがユーザーへ転嫁されつつある。エンジニアリング上の意思決定として、agent オーケストレーションの予算モデルはアカウント総クォータで設計し、オープンソースモデルをオーバーフロー層として保持する必要がある。
> 11-20/11-25 の「フロンティア/オープンソースの価格差拡大」という判断を引き継ぎ、今日は「枠の統合」という新しい変数が加わった。

**形式検証が数学の裁定からエンジニアリング監査へ拡散**：Anthropic がより短い GRH Lean 検証バージョンを公開（HN 396👍）、今週の Lean 本流を継続。エンジニアリング側の実際の変化は、Lean 4 ツールチェーンの超大規模でのコンパイル時間と trusted base について再利用可能な公開サンプルができたことだ。Lean でプロトコル/コントラクト検証を行うことを評価しているチームは、実規模でのベンチマークが可能になった。
